# Reference documents

The guide draws on official documents published by the CPA bodies. **The documents themselves are not in this repository.** They belong to their publishers, so this page lists where to download each one yourself.

To make the guide's "local copy" links work, save each file under the folder and file name shown below, next to `CPA-Professional-Program-Guide.html`. For example: `references/01-national-core/CPA-Competency-Map.pdf`.

- Addresses were checked on 2026-11-17. Program details were still being finalized, so a newer version may have replaced a file.
- The images in `04-west-cpawsb` and `05-quebec` are graphics shown on the listed pages; save the image from the page.
